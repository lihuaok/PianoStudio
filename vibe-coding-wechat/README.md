# Vibe Coding 不会消除工程的壁垒 · 公众号图文稿

一篇技术思辨长文的完整发布物料：排版稿 + 4 张工程制图级矢量图解 + PNG 成品图。

## 目录

| 文件 | 用途 |
|---|---|
| `index.html` | **排版成品**（打开即用）。顶部「复制正文（保留样式）」→ 粘贴进微信公众号编辑器；「下载全部插图 PNG」导出配图 |
| `正文纯文字.md` | 无格式保底版，手动粘贴进编辑器后再加粗 |
| `charts/*.svg` | 4 张配图的矢量源文件，可自由缩放 / 改色 / 放进 PPT |
| `screenshots/fig-01..04.png` | 1360×720 成品图（2 倍图），公众号直接插图用 |
| `tools/fig-preview.html` | 4 张图并排核对页，改图后用来逐张复核 |
| `build.mjs` | 构建脚本：把 `charts/` 内联注入 `index.html` |

## 改图 / 重出

```bash
node build.mjs          # 注入内联图 + 重生成预览页与单图页
```

改图流程：直接编辑 `charts/fig-0X-*.svg` → 跑上面这条命令 → 用 Edge headless 对
`tools/fig-preview.html` 逐屏截图核对文字压盖 → 确认无误后重新导出 `screenshots/*.png`。

## 图解一览

| 图号 | 名称 | 说清什么 |
|---|---|---|
| V-01 | 能力分工 | 上半区（AI 可独立完成）与下半区（必须由人承担）的分界 |
| V-02 | 认知上限定律 | 实际产出 = min(模型能力, 使用者认知)，交点即「临界点」 |
| V-03 | AI 代码的隐性缺陷 | 水面以上「能跑」，水面以下沉着边界/资源/并发/安全四层窟窿 |
| V-04 | 原型 vs 生产层序 | 同样的自然语言，Demo 是 3 层，生产系统是 6 层 |

## 样式约定（改排版时别破坏）

- 一切样式**内联**，不用 class / flex / grid —— 微信公众号编辑器会过滤。
- 配色：墨蓝 `#1B3A5C`（主）/ 赭橙 `#B4552D`（强调）/ 纸底 `#FAF7F2` / 浅蓝 `#EEF3F8` / 高亮 `#FDF3DC`。
- 正文 677px 宽、16px 字、行高 1.9、段首不缩进。
- 每张 SVG 内的 `marker` id 必须带图号前缀（`fig01-ar`），多张图内联同一页面时不能重名。
